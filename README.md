# api-mwo-profile

Backend di gestione profili (modulo `mwo_controller`): API REST in Java EE con RESTEasy (JAX-RS).

## Stack

- Java EE (JAX-RS / RESTEasy)
- Maven
- JSON (json-simple)

## Build

```bash
mvn clean package
```

L'artefatto prodotto va rilasciato su un application server compatibile Java EE (es. WildFly / JBoss).

## Contesto

Coppia backend/frontend:

- `api-mwo-profile` — questo modulo: API / controller
- `mwo_app_profile` — interfaccia utente
