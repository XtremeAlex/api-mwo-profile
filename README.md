# xtr-profile-api

Backend di gestione profili: API REST in Java EE con RESTEasy (JAX-RS).

## Stack tecnologico

- Java EE (JAX-RS / RESTEasy)
- Maven
- JSON (json-simple)

## Build

```bash
mvn clean package
```

L'artefatto prodotto va rilasciato su un application server compatibile Java EE (es. WildFly / JBoss).

## Contesto

Coppia backend/frontend:

- `xtr-profile-api` — questo modulo: API / controller
- `xtr-profile-ui` — interfaccia utente
